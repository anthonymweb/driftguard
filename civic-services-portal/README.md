# Civic Services Portal

A standalone, fictional government-style service portal for local UI research and controlled web application testing. It does not represent a real government or public authority.

## Run locally

```powershell
npm install
npm run dev
```

Open <http://127.0.0.1:5175>.

Sample request references are kept in browser `sessionStorage`. Requests are not sent to an office or backend, and the site does not issue official records, accept payments, or request personal identity information.
